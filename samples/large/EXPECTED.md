# large 範例：預期結果

```powershell
dotnet run --project tools/MealRoute.Cli -c Release -- solve --project samples/large/project.mealroute.json --iterations 1000 --seconds 600
```

| 指標 | 預期 |
|---|---|
| 路網 | 19,919 節點、68,509 有向邊、14 個小分量；匯入約 0.3 秒 |
| 吸附警告 | 3（S001–S003 位於城市南緣外） |
| L1 快取 | 約 3.7 秒（215 個地點 × 39 個取樣時刻，24 邏輯核心） |
| 第一個可行解 | 匯入起算約 5 秒（驗收上限 15 秒） |
| 結果（種子 33、每次 1,000 迭代 × 4 次） | 必送 163/163 全部服務、選送全部服務、**10 車**（15 車可用）、總行車約 16:25、總工時約 31:07 |
| 休息 | **1 次**：V01（長工時車，09:00–18:00）服務 6 個郊區村落站（S195–S200），往返約 50 公里郊區道路，累計行車超過 4.5 小時，必須在某站服務後休息 30 分鐘（此設定下評估器選在 S118 服務後） |
| 記憶體峰值 | 約 140 MB |

檢查方式：
- 必送站全數服務；V01 的路線包含 S195–S200，且 S118 標示「服務後休息」。
- 路線單（App 的列印/匯出）中 V01 的到達時刻在休息後整體延後 30 分鐘。
- 效能數字與 60 秒改善結果另列於專案 README。
